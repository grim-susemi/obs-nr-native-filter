# 영상 업스케일 및 프레임 생성

OBS에서 소스의 **필터 → 효과 필터 → + → 영상 업스케일 및 프레임 생성**을 선택하고 **업스케일 및 선명화**를 켭니다.
업스케일은 별도 미리보기 창을 열지 않아도 적용됩니다. Native NR은 노이즈 제거만 합니다.
기존 장면의 **NVIDIA VFG** 필터가 있으면 그 필터의 속성에서 업스케일을 켜면 됩니다.

| 소스 출력 크기 | 동작 |
| --- | --- |
| 원본 크기 | 이중선형 방식에서는 CAS 선명화만 적용하고, NVIDIA DLSS 방식에서는 원본 크기에서 DLAA를 적용합니다. |
| 1440p / 4K | 16:9의 1920×1080 입력을 각각 2560×1440 / 3840×2160으로 확대합니다. |
| 끄기 | 확대와 선명화를 모두 끕니다. 프레임 생성 미리보기를 유지하려면 필터 눈 아이콘 대신 **업스케일 및 선명화**만 끄세요. |

16:9가 아니면 입력 비율을 유지하고 목표 크기를 덮도록 확대합니다. 이미 목표 이상의 입력은
축소하지 않습니다. OBS 캔버스와 방송 출력 설정은 바꾸지 않습니다. 예를 들어 최종 4K 방송을
하려면 OBS의 비디오 설정에서도 그 해상도를 지정해야 합니다.

**기존 장면에서 전환:** Native NR은 소스 크기를 바꾸지 않으며 예전에 저장한 DLSS/CAS 값을
더 이상 적용하지 않습니다. 기존 독립 효과는 기존 장면에서 작동하지만 새 효과 목록에서는
숨깁니다. 한 필터에서 비교하려면 크기·모델·강도를 새 통합 효과에 옮긴 다음 기존 독립 효과를 끄세요. 예를 들어
`4K / 프리셋 L / CAS 1.00`은 `4K / NVIDIA DLSS / 프리셋 L / CAS 100%`에 해당합니다.
Native NR 뒤에서 사용하면 노이즈 제거된 영상을 확대합니다. OBS 내장 **선명하게** 필터가
켜져 있으면 선명화가 중복 적용됩니다.

미리보기를 연 채 **원본 디테일과 비교**를 전환하면 DLSS와 CAS만 끄고, 같은 크기로
이중선형 확대합니다. 원본 해상도 자체를 비교하려면 **업스케일 및 선명화**를 끄면 됩니다.
미리보기 창의 내부 전송 해상도는 열린 동안 고정됩니다. 새 해상도를 미리보기 자체에
적용하려면 창을 한 번 다시 여세요. 이 조작은 OBS 캔버스 크기를 바꾸지 않습니다.

**확대 방식**이 이중선형이면 NVIDIA 런타임 없이 크기 조절과 AMD FidelityFX CAS를 사용할 수
있습니다. NVIDIA DLSS에는 별도 `nvngx_dlss.dll`이 필요합니다. 효과가 현재 OBS의
`bin/64bit/dlss`에 설치된 런타임을 자동으로 찾으며, DLSS를 사용할 수 없으면 이중선형 확대와 CAS를 사용합니다.
CAS를 끄려면 선명화를 0%로 설정하세요.
HDR 입력과 효과 셰이더를 만들지 못한 경우에는 크기와 영상이 원본 그대로 통과합니다.

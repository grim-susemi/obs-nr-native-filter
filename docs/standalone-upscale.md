# 업스케일 및 선명화 (CAS)

OBS에서 소스의 **필터 → 효과 필터 → + → 업스케일 및 선명화 (CAS)**를 선택합니다.
Native NR 및 NVIDIA VFG를 추가하지 않아도 작동합니다. 기존 장면과 필터 설정은 자동으로 바뀌지 않습니다.

| 소스 출력 크기 | 동작 |
| --- | --- |
| 원본 크기 | 크기를 유지하고 CAS 선명화만 적용합니다. |
| 1440p / 4K | 16:9의 1920×1080 입력을 각각 2560×1440 / 3840×2160으로 확대합니다. |
| 끄기 | 확대와 선명화를 모두 끕니다. OBS의 필터 눈 아이콘으로도 비활성화할 수 있습니다. |

16:9가 아니면 입력 비율을 유지하고 목표 크기를 덮도록 확대합니다. 이미 목표 이상의 입력은
축소하지 않습니다. OBS 캔버스와 방송 출력 설정은 바꾸지 않습니다. 예를 들어 최종 4K 방송을
하려면 OBS의 비디오 설정에서도 그 해상도를 지정해야 합니다.

**확대는 한 곳에서만 켜세요.** Native NR과 같이 쓰려면 Native NR 내 업스케일과 CAS를 끄고,
NR이 처리한 결과를 이 효과로 보내세요. VFG는 기존 위치를 유지하고, VFG에 확대된 프레임을
공급하려는 경우에만 이 효과를 VFG가 받는 쪽에 배치하세요. 반대로 Native NR에서 이미 확대한다면
이 효과는 원본 크기(선명화만) 또는 끄기로 두세요. CAS 0%는 확대만 적용합니다.

이 효과는 OBS GPU 렌더러에서 bilinear 확대와 AMD FidelityFX CAS를 사용합니다. NVIDIA 런타임,
DLSS용 모션 벡터, Native NR 처리, OBS 내장 선명화 필터에 의존하지 않습니다.
HDR 입력과 효과 셰이더를 만들지 못한 경우에는 크기와 영상이 원본 그대로 통과합니다.
